# ASCII FPV · 楼宇穿越

第一视角 ASCII 飞行游戏。画面**不是真 3D 渲染**，而是自写的软件光栅化器（透视投影 + 1/z 深度缓冲 + 近裁剪 + 逐字符着色），输出目标是「字符单元格」而非像素 —— 每一格 = 1 个字符 + 1 个颜色，整屏再按颜色分段刷到画布上。

```
                        =============
       ============*******===========:
      ====*****################========          --------------
      #:::::#  #....#:::#      :::   ##         |  #....#:::#  |
      #:::::#  #....#:::#..#::#   ######        |  #....#:::#  |
------#:::::#  #....#:::#..#::#------------     |  ##[+]#####  |
                                                 -------------- 150x48 CHARS
```

## 快速开始

直接双击 `index.html` 即可（也可以起静态服务器：`python -m http.server 8000`，再打开 `http://localhost:8000`）。

启动后进入**开始界面**，选模式即可起飞；界面里可随时切换中文 / English。

> 项目**零依赖、无构建**：不使用 ES Module，就是为了让 `file://` 双击打开依然可用（ES Module 在 `file://` 下会被 CORS 拦截）。各模块按 `index.html` 里的 `<script>` 顺序加载，统一挂到全局 `AFP` 命名空间。

## 玩法

起飞前有 2.2 秒倒计时；撞到地面、楼房或空中障碍物即坠机，超时也算失败，按 `R` / 轻点屏幕重来。

### 闯关模式（8 关）

按顺序穿过所有光环即通关，逐关解锁，并记录最佳用时（刷新纪录时结算界面会标注「新纪录」）：

| 关卡 | 光环 | 半径 | 高度区间 | 限时 |
|---|---|---|---|---|
| 1 起飞 | 4 | 16 m | 28–62 m | 90 s |
| 2 楼宇之间 | 6 | 15 m | 30–82 m | 110 s |
| 3 城市环线 | 8 | 15 m | 40–112 m | 130 s |
| 4 低空穿行 | 8 | 14 m | 24–52 m | 100 s |
| 5 高空索道 | 9 | 14 m | 110–190 m | 140 s |
| 6 迷城 | 11 | 12 m | 42–122 m | 150 s |
| 7 极限穿梭 | 12 | 10 m | 45–150 m | 150 s |
| 8 王者航线 | 14 | 11 m | 50–200 m | 180 s |

关卡由种子确定性生成：起点自动选在低矮城区的路口，光环沿随机游走落在**道路中心线**上（因此不会被楼房堵死）。同一关卡每次生成完全一致。

### 自由飞行

没有目标，只比谁飞得远，记录最远距离。

## 操作

### 键盘

| 按键 | 作用 |
|---|---|
| `W` / `S` | 减小 / 增加俯仰角（±45° 限幅） |
| `A` / `D` | 滚转角速率控制（±45° 限幅） |
| `Z` / `X` | 加速 / 减速（10 ~ 50 m/s） |
| `R` | 坠机 / 超时后重生 |
| `[` `]` | 字符密度（分辨率） |
| `H` / `C` | HUD 开关 / 碰撞开关（关掉可穿楼观光） |
| `空格` / `P` / `Esc` | 暂停 / 继续 |

滚转 45° 时偏航角速度线性到达 90°/s，构成协调转弯。

### 触屏：左右分屏（默认）

沿用「左手管方向、右手管油门」的常见布局：

- **左半屏**：任意处按住拖动 = **姿态摇杆**（左右滑滚转、上下滑俯仰，上滑俯冲 / 下滑爬升），离基点越远舵量越大；HUD 上画出基点方框与摇杆头
- **右半屏**：上下拖动 = **油门**（上滑加速 / 下滑减速，松手回中）；HUD 右侧有纵向油门刻度条
- 两个半屏可同时操作；**轻点任一半屏** = 暂停 / 继续，坠机后轻点即重来；暂停与坠机面板**外的暗区**轻点同样可以继续 / 重来
- 设置里可切回**单摇杆**布局（单指拖动 = 姿态，双指上下滑 = 油门）

小屏触屏设备会自动降低字符密度（字符更大、帧率更稳）；面板内容比屏幕高时可以用手指上下滚动。

### 陀螺仪

设置 → 操控方式可切「摇杆 / 陀螺仪 / 摇杆 + 陀螺仪」。切到陀螺仪后倾斜设备即可控制俯仰与滚转：

- 灵敏度可调，俯仰 / 滚转可分别反向
- 第一帧姿态自动作为零位，也能随时「校准」把当前姿势设为零位
- **收不到传感器数据时一定回退摇杆**，不会失去操控：iOS 13+ 需要授权（被拒会在设置里说明原因）、设备/浏览器不支持、或声明了 `DeviceOrientationEvent` 却永远不触发（桌面浏览器，以及 `http://` 局域网地址下被判定为非安全上下文而屏蔽）都属于这种情况
- 陀螺仪模式下油门仍用右半屏上下滑

## 城市

世界是**可无限平铺**的：24×24 个街区模板构成 1536 m 周期，每 64 m 一个街区、16 m 宽道路，按坐标取模取用，所以飞多远都是同一座连贯的城。视野 620 m，雾随距离衰减。

城区由两层低频噪声切成**五类生物群系**，飞过去能明显感到城市在变化（下表为 576 个模板街区的实测分布）：

| 群系 | 特征 | 模板街区 | 楼高上限 |
|---|---|---|---|
| 市中心 | 玻璃幕墙高楼群，偶发地标尖塔，亮窗最多 | 11 | 245 m |
| 商业区 | 中高层混排 | 103 | 245 m |
| 住宅区 | 红砖低层 + 大量树木与小公园 | 181 | 77 m |
| 工业区 | 低矮大跨度厂房、裸土地面 | 99 | 88 m |
| 公园区 | 成片树林与水面 | 182 | 62 m |

市中心在噪声分布里是最稀有的一块，通常要飞一段才会遇到。HUD 左上角始终显示当前所在城区。

**图例**：灰蓝色 `#` 楼房（琥珀色为亮着的窗户）· 绿色 `&` 树木 · 灰色 `=` 与黄色虚线 道路 · 蓝色 `~` 公园水面 · 公园与工业区有专属地面材质。

**空中移动障碍物**（撞上即坠机；模板内共 375 个实例，分布在 10 ~ 326 m 高度）：

| 障碍物 | 外观 | 行为 | 群系倾向 |
|---|---|---|---|
| 气球 | 竖向色带气囊 + 吊绳吊篮 | 缓慢漂移 + 上下浮动 | 公园 / 住宅区多 |
| 飞行器 | 机身 / 主翼 / 尾翼 + 左红右绿航行灯 | 绕圈巡航，沿切线方向飞 | 市中心 / 商业区多 |
| 无人机 | X 形机架 + 闪烁警示灯 | 小半径巡逻 | 工业区多 |

障碍物位置由「生成参数 + 当前时间」确定性推出，渲染与碰撞必然看到同一个位置；全部生成在所在街区（及 3×3 邻域）楼顶之上，不会穿楼。

## 碰撞判定

判定比看得见的轮廓**更宽松**，避免「看着明明还有距离却撞了」；但**楼体是实心的**：

| 判定 | 规则 |
|---|---|
| 地面 | 离地 0.6 m 以下才算撞地 |
| 楼体 | 边界就是**真实墙面**（进不去），高度以屋面为界；贴墙外侧飞过不判撞 |
| 气球 | 判定球 = 可见气囊半径 × 0.85 + 0.4 m |
| 飞行器 | 判定球 4.0 m（只覆盖机身，翼尖可擦过；机身半长 5.2 m、翼展 ±7 m） |
| 无人机 | 判定球 1.3 m（机身 ±1.15 m） |

全部参数集中在 `AFP.cfg.HIT`，便于继续调整。

## 界面与设置

七块 DOM 面板叠在 ASCII 画面之上：**开始界面 / 选关 / 操作说明 / 设置 / 暂停 / 坠机 / 通关结算**，由有限状态机（`boot → menu → levels / settings / help → play ⇄ pause → crash / result`）驱动，文案全部走 i18n，切换语言即时重绘。

设置项（改动即时保存到浏览器 `localStorage`）：

中文 / English · 操控方式（摇杆 / 陀螺仪 / 混合）· 摇杆灵敏度 · 陀螺仪灵敏度与反向 · 触屏布局（分屏 / 单摇杆）· **字符密度** · HUD 开关 · 碰撞开关 · 清除最远距离记录 · 清除关卡进度。

**字符密度**显示的是**实际排出来的「列 × 行」**，与 HUD 右下角 `150x48 CHARS` 是同一组数字（`[` `]` 或面板上的 ± 都按实际列数增减，另有「自动」档）。由于字符格宽度取整成整数设备像素（保证字形清晰），相邻可用列数是离散的，例如 150 / 160 / 170。**下限 84 × 25**（实测保持可玩性的最小密度），到顶后「-」自动禁用；窗口特别扁时行数下限会先起作用，自动加密列数。

本地存储键：`asciifpv.settings`（设置）、`asciifpv.progress`（关卡进度与最佳用时）、`asciifpv.best`（最远距离）。

## 开发与自检

零依赖，无需安装、无需打包：

```bash
npm test            # 等价于 node tests/run.js
```

测试自带迷你 DOM 与 vm 沙箱，**离线可跑**，直接加载 `index.html` 声明的真实源码（脚本清单就是唯一的「构建配置」）。覆盖：模块加载与脚本顺序、中英词条一一对应、地图与生物群系形态、障碍物生成 / 移动 / 碰撞 / 渲染出色、楼体实心性（逐点扫描）、碰撞宽容度、状态机各路径、飞行力学与限幅、闯关流程（确定性、顺序判定、通关、超时、解锁、选关界面）、设置持久化、密度调节与下限、陀螺仪映射与授权、触屏分屏（左姿态 / 右油门、死区、双指并发、轻点）、主循环，以及一条 23 步全流程验收。

浏览器控制台调试接口：

```js
__ASCIIFPV__.state()        // 当前状态
__ASCIIFPV__.ui('free')     // 触发界面动作
__ASCIIFPV__.action('pause')
__ASCIIFPV__.info()         // 网格 / 相机 / 飞行数据
__ASCIIFPV__.setCam({x, y, z, yaw, pitch, roll, spd})
__ASCIIFPV__.step(1 / 120)  // 推进一帧物理
__ASCIIFPV__.dump()         // 把当前画面导出成文本
```
