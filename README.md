# ASCII FPV · 楼宇穿越

第一视角 ASCII 飞行游戏。全部画面由彩色 ASCII 字符排列而成，非真 3D 渲染 —— 自写软件光栅化器（透视投影 + 1/z 深度缓冲 + 逐字符着色），输出目标是「字符单元格」而非像素。

```
                        =============
       ============*******===========:
      ====*****################========
      #:::::#  #....#:::#      :::   ##
      #:::::#  #....#:::#..#::#   ######
------#:::::#  #....#:::#..#::#------------
```

## 玩法

两种模式，主菜单里选：

- **闯关模式** — 8 关，按顺序穿过所有光环即可通关，有计时与限时；穿过全部关卡后解锁下一关，最佳用时会记下来。
- **自由飞行** — 没有目标，只比谁飞得远（记录最远距离）。

起飞前有 2.2 秒倒计时；撞到地面、楼房或空中障碍物就坠机，超时也会失败，按 `R` / 轻点屏幕重来。

## 操作

### 键盘

| 按键 | 作用 |
|---|---|
| `W` / `S` | 减小 / 增加俯仰角（±45° 限幅） |
| `A` / `D` | 滚转角速率控制（±45° 限幅） |
| `Z` / `X` | 加速 / 减速（10 ~ 50 m/s） |
| `R` | 坠机 / 超时后重生 |
| `[` `]` | 字符密度（分辨率） |
| `H` / `C` | HUD 开关 / 碰撞开关（关掉可穿楼观光） |
| `空格` / `P` / `Esc` | 暂停 / 继续 |

滚转 45° 时偏航角速度线性到达 90°/s，构成协调转弯。

### 触屏（左右分屏，默认）

- **左半屏上下滑** — 油门：上滑加速、下滑减速，松手回中；左侧刻度条实时显示油门
- **右半屏任意处按住拖动** — 姿态摇杆：左右滑滚转、上下滑俯仰（上滑俯冲 / 下滑爬升），离基点越远舵量越大，HUD 上画出基点方框与摇杆头
- 两个半屏可以同时操作；**轻点任意半屏** = 暂停 / 继续，坠机后轻点即重来
- 设置里可切回**单摇杆**布局（单指拖动 = 姿态，双指上下滑 = 油门）

### 陀螺仪

设置 → 操控方式可切「摇杆 / 陀螺仪 / 摇杆 + 陀螺仪」。切到陀螺仪后倾斜设备即可控制俯仰与滚转：

- 灵敏度可调，俯仰 / 滚转可分别反向
- 第一帧姿态自动作为零位，也能随时「校准」把当前姿势设为零位
- iOS 13+ 需要在用户手势中授权运动与方向传感器；拒绝授权或不支持时自动回退摇杆，不会失去操控

## 场景元素

城区按低频噪声分成五类**生物群系**，飞过去能明显感到城市在变化：

| 群系 | 特征 |
|---|---|
| 市中心 | 玻璃幕墙高楼群，偶发地标尖塔，亮窗最多 |
| 商业区 | 中高层混排 |
| 住宅区 | 红砖低层 + 大量树木与小公园 |
| 工业区 | 低矮大跨度厂房、裸土地面、无人机多 |
| 公园区 | 成片树林与水面，气球最多 |

- 灰蓝色 `#`：楼房（琥珀色为亮着的窗户）；绿色 `&`：树木
- 灰色 `=` 与黄色虚线：道路；蓝色 `~`：公园水面
- 空中的**移动障碍物**（撞上即坠机）：彩色**气球**（缓慢漂移、上下浮动，带吊绳吊篮）、银色**飞行器**（绕圈巡航，左红右绿航行灯）、**无人机**（小半径巡逻，闪烁警示灯）
- HUD 左上会显示当前所在城区名

## 设置（自动存到本地浏览器）

语言（中文 / English）· 操控方式（摇杆 / 陀螺仪 / 混合）· 摇杆灵敏度 · 陀螺仪灵敏度与反向 · 触屏布局（分屏 / 单摇杆）· **字符密度**（显示的是实际排出来的「列 × 行」，与 HUD 右下角 `150x48 CHARS` 是同一组数字；`[` `]` 或面板上的 ± 都按实际列数增减，另有「自动」档。**下限 84 × 25**——实测保持可玩性的最小密度，到顶后「-」会自动禁用；窗口特别扁时行数下限会先起作用，自动加密列数）· HUD 开关 · 碰撞开关 · 清除最远距离记录 · 清除关卡进度。

## 运行

直接双击打开 `index.html` 即可（也可以起个静态服务器）。

> 之所以不用 ES Module、也没有任何构建步骤，就是为了让 `file://` 双击打开依然可用（ES Module 在 `file://` 下会被 CORS 拦截）。各模块按 `index.html` 里的 `<script>` 顺序加载，统一挂到 `AFP` 命名空间。

## 开发

零依赖，无需安装、无需打包：

```bash
node tests/run.js      # 无头自检（迷你 DOM + vm 沙箱，离线可跑）
```

测试覆盖：模块加载与脚本顺序、i18n 词条完备性、地图与生物群系形态、障碍物生成/移动/碰撞与渲染出色、状态机各条路径、飞行力学与限幅、闯关流程（确定性、顺序判定、通关、超时、解锁）、设置持久化、陀螺仪映射与授权、触屏分屏操控、主循环。

浏览器里也可以用控制台调试：

```js
__ASCIIFPV__.state()        // 当前状态
__ASCIIFPV__.ui('free')     // 触发界面动作
__ASCIIFPV__.info()         // 网格 / 相机 / 飞行数据
__ASCIIFPV__.dump()         // 把当前画面导出成文本
```
