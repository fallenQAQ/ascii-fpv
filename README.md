# ASCII FPV · 楼宇穿越

第一视角 ASCII 飞行游戏。全部画面由彩色 ASCII 字符排列而成，非真 3D 渲染 —— 自写软件光栅化器（透视投影 + 1/z 深度缓冲 + 逐字符着色），输出目标是「字符单元格」而非像素。

## 玩法

桌面（键盘）：

- **W / S** — 减小 / 增加俯仰角（±45° 限幅）
- **A / D** — 滚转角速率控制（±45° 限幅），滚转 45° 时偏航角速度线性到达 90°/s，构成协调转弯
- **Z / X** — 加速 / 减速（10 ~ 50 m/s）
- **R** — 坠机后重生
- **[ ]** — 字符密度（分辨率）
- **H / C / P** — HUD 开关 / 碰撞开关 / 暂停

移动端（触屏，滑动屏幕任意处即可操控）：

- **单指按住滑动** — 屏幕任意处即虚拟摇杆：左右滑动控制滚转，上下滑动控制俯仰（上滑俯冲 / 下滑爬升，与 W / S 一致），偏移越大速率越快，松手回中；HUD 中央的琥珀色标记指示当前杆位
- **双指上下滑动** — 加速 / 减速（10 ~ 50 m/s）
- **轻点屏幕** — 暂停 / 继续；坠机后轻点即重生
- 小屏触屏设备会自动降低字符密度，单个字符更大、运行更流畅

## 场景元素

- 灰蓝色 `#`：楼房（琥珀色为亮着的窗户）
- 绿色 `&`：树木
- 灰色 `=` 与黄色虚线：道路
- 天空：黑底

## 运行

直接双击打开 `index.html`（或起个静态服务器），点击任意处 / 按任意键起飞。
